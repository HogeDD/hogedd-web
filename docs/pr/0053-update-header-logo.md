# Headerのロゴを変更する

## 背景

Headerで使用していた正方形のロゴを、縦長の新しいHogeDDロゴへ変更した。既存の正方形固定レイアウトでは画像が横へ引き伸ばされ、新しいシルエットを正しく表示できなかった。

## 決定したこと

- ロゴ画像を`public/HogeDD.png`へ変更する。
- 画像の実寸である`720×1030`をNext.jsの`Image`へ指定する。
- CSSでは高さだけを指定し、幅は画像比率から自動算出する。
- ロゴの表示高はモバイル40px、タブレット以上48pxとする。
- ロゴ横の`HogeDD`はモバイル18px、タブレット以上20pxとする。
- 新ロゴは透過画像の形状を活かし、角丸を付けない。

## 理由

実寸の縦横比をNext.jsへ渡し、幅を自動算出することで、画像を変形させずレイアウトシフトも防げる。

ロゴを小さくすると文字との高さは揃うが、新しいロゴの線や立体表現が見えにくくなった。ロゴの視認性を優先して40〜48pxへ戻し、文字だけを以前より大きくすることでブランド名とのバランスを取った。

ファイル名の変更は、同名画像を差し替えた際にブラウザや画像最適化キャッシュから旧画像が表示され続ける問題も回避する。

## 検討した代替案

### 正方形の領域へ収める

既存レイアウトは維持できるが、縦長ロゴが小さく見えるか、幅と高さを固定すると変形するため採用しない。

### ロゴを文字と同程度の高さにする

整列感は高まるが、ロゴの細部が見えにくく存在感も弱くなったため採用しない。

### 既存のファイル名を維持する

差分は小さいが、確認環境で旧画像のキャッシュが残った。確実に新画像へ切り替えるためファイル名を変更する。

## トレードオフ

- ロゴは文字より縦方向に大きく見える。
- 今後画像を変更する場合は、実寸の`width`と`height`も確認する必要がある。
- ファイル名を参照している箇所が増えた場合、名称変更の影響範囲が広がる。

## テスト・検証内容

- Prettierによるformat確認。
- ESLintによる静的解析。
- TypeScriptの型チェック。
- Vitestのunit test。
- Next.jsのproduction build。
- ローカル画面で画像比率とHeader内の配置を確認。

- ロゴ画像を再度変更するとき。
- モバイルでブランド名やナビゲーションが収まらなくなったとき。
