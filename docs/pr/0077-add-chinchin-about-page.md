# #77 ちんちんゲームのAboutページを作る

## 背景

ちんちんゲームを開いたユーザーがすぐ遊べる状態を維持しながら、制作動機と〇〇DDを必要な人へ伝えられる場所が必要だった。

## 決定したこと

- `/apps/chinchin/about`を追加し、共通の`AppAboutShell`を使う。
- 開発DDは「こどおじDD」とする。
- 制作動機は本人から提供された文章を3段落へ整えて掲載する。
- 番組名とコーナー名はTBSラジオ公式表記へ合わせる。
- 番組公式ページと、コーナーから生まれた書籍のAmazon商品ページを参考リンクとして掲載する。
- YouTubeは未公開のため導線を表示しない。
- Guideは未実装のままにし、ナビではAboutだけを有効化する。

## 理由

制作動機をゲーム画面へ追加すると、開いてすぐ遊べる体験を弱める。共通Aboutページへ分けることで、ゲーム本体を変えずにHogeDDらしい動機を残せる。

## 検討した代替案

- ゲーム画面の冒頭へ制作動機を掲載する。
- YouTube公開前に仮の動画導線を置く。

どちらも現在の情報設計と公開状態に合わないため採用しなかった。

## トレードオフ

- Guideが完成するまではアプリ内ナビの3ページすべてを利用できない。
- 放送日時を現在形で記載するため、番組編成が変わった場合は文章の更新が必要になる。

## テスト・検証内容

- About routeが共通Shellを利用すること。
- `layout.tsx`でAboutナビが有効になること。
- desktopとmobileで本文とナビを確認する。

## 今後の見直し条件

- 番組の放送日時や公式ページが変更された場合。
- YouTube公開時にAboutへ動画導線を追加する場合。
