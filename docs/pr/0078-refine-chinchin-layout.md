# #78 ちんちんゲームの共通テーマとApp画面を整える

## 背景

App、About、Guideの共通ナビと共通shellは揃っていたが、ちんちんゲームにはアプリ固有テーマが未適用だった。また、App画面は共通shellの内側でも全画面高さを持ち、Guideと重複する説明がゲーム本体より先に目へ入る構成だった。

## 決定したこと

- ちんちんゲームの3ページへ、肌色に近い温かさのある`coral`テーマを適用する。
- App画面はタイトル、現在の手番、盤面、リセットだけに絞る。
- App画面の節ラベルは簡潔な`Board`とする。
- mobileでは手番を盤面の直前に置き、desktopでは盤面の右側へ配置する。
- 背景装飾、余白、角丸、影はApp画面内で整えるが、配色はテーマのCSS変数だけを使う。
- 勝利マスの既存表示は維持し、色の直書きだけテーマ変数へ置き換える。

## 理由

App画面を開いた直後に遊べる状態を保ちつつ、AboutとGuideを含む3ページを同じアプリとして見せるため。mobileで手番を盤面より先に確認でき、desktopでは盤面を主役にしたまま補助情報を横へ逃がせる。

## 検討した代替案

- App画面にもルール説明を残す。
- App専用の独自テーマを追加する。
- ステータスを盤面の下へ固定する。

ルール説明はGuideと役割が重複する。既存の`coral`で十分にアプリ固有の雰囲気を出せるため新しいpresetは不要。ステータスを下へ固定すると、mobileで手番を確認してから盤面へ戻る移動が増えるため採用しなかった。

## トレードオフ

- 初めて遊ぶ人は詳しいルールをGuideで確認する必要がある。
- App画面固有の装飾は残るが、色とページ間ナビは共通機構に従う。

## テスト・検証内容

- `coral`テーマがlayoutから渡されること。
- App画面が共通shellと重複する全画面高さを持たず、色を直書きしないこと。
- desktopとmobileでApp、About、Guideの移動、盤面操作、リセット、overflowを確認する。
- Prettier、ESLint、TypeScript、Vitest、Next.js production build。
