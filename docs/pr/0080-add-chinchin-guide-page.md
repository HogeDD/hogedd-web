# #80 ちんちんゲームのGuideページを作る

## 背景

ちんちんゲームには盤面、手番、勝利条件がある。ゲーム画面の説明量を増やさず、必要なときだけ遊び方を確認できる場所が必要だった。

## 決定したこと

- `/apps/chinchin/guide`を追加し、共通の`AppGuideShell`を使う。
- 最初の操作、基本操作、画面の見方、ルール、困ったときの5セクションをすべて掲載する。
- 勝利条件として「ちんちん」と「んちんち」の両方を明記する。
- 横、縦、斜めの勝利例を5×5のミニ盤面で図示する。
- Guideはローカル2人対戦の説明へ絞り、削除予定のオンライン対戦には言及しない。
- App/About/Guideのナビをすべて有効化する。

## 理由

ゲーム画面へ長い説明を置くと、開いてすぐ遊べる体験を弱める。共通Guideへ分離することで、本体を簡潔に保ちながらルールと注意事項を一か所で確認できる。文字だけでは盤面上の成立方向を理解しづらいため、勝利例は図でも示す。

## 検討した代替案

- ゲーム画面へルール全文を追加する。
- 初回起動時にチュートリアルやモーダルを表示する。

どちらもすぐ遊べる体験を妨げ、#80の範囲を超えるため採用しなかった。

## トレードオフ

- 文章による説明であり、対話式の練習機能は提供しない。
- オンライン対戦機能は別Issueで削除するため、このIssueではゲーム本体との一時的な差異が残る。

## テスト・検証内容

- Guide routeが共通Shellと5セクションを利用すること。
- `layout.tsx`でApp/About/Guideがすべて有効になること。
- desktopとmobileで表示とAppへの戻り導線を確認する。
