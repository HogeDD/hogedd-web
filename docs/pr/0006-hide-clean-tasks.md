# 0006: Clean Tasks を公開導線から外す

## 背景

`clean-tasks` は実装の練習用に残したいが、今後は新しいアプリを主役にしていくため、既存アプリをサイト上の導線から外したかった。

## 決定したこと

- `frontend/app/page.tsx` から `Clean Tasks` のカードを外す。
- `frontend/app/apps/page.tsx` から `Clean Tasks` の公開導線を外す。
- 実装自体は削除せず、直接 URL で見られる状態は残す。

## 理由

この時点で `clean-tasks` を前面に出すと、新しいアプリを作る段階で視線が分散する。表示面だけ外しておけば、既存の練習用コードはそのまま残しつつ、新しいアプリに注力できる。

## 検討した代替案

- `clean-tasks` のルート自体を削除する案
  - まだ学習用の土台として参照したいので見送った。
- `clean-tasks` を `/apps` に残したままラベルだけ変える案
  - まだ見せる理由が弱かったため、完全に導線から外す形を優先した。

## トレードオフ

直接 URL を知っていれば引き続き見られるため、完全な非公開ではない。一方で、サイト内の導線は新しいアプリに集中できる。

## テスト・検証内容

- `npm run format:check`
- `npm run lint`
- `npm run typecheck`
- `npm run build`

## 今後の見直し条件

- 新しいアプリが公開できる状態になったとき
- `clean-tasks` をアーカイブ扱いにしたいとき
- app 一覧の表示ルールが増えたとき
