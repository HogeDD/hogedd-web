# 0008: ローカル2人対戦のちんちんゲームを追加する

## 背景

HogeDD の新しいアプリとして、5x5 の盤面で2人が交互に文字を置くゲームを追加する。将来的にはオンラインランダム対戦も検討するが、まずはルールと UI を固めるためにローカル2人対戦へ絞る。

## 決定したこと

- `/apps/chinchin-game` にゲームページを追加する。
- Player 1 は `ち`、Player 2 は `ん` を固定で担当する。
- 勝利判定は、最後に置いたマスを含む4マス連続が `ちんちん` または `んちんち` になった場合とする。
- 方向は縦、横、斜めの4方向を見る。
- 完成した4マスだけ薄茶色にし、文字にブラーをかける。
- `/apps` の一覧にも動画準備中カードとして追加する。

## 理由

オンライン対戦を先に入れると、WebSocket、room、matching、再接続、同期ずれなどが一気に増える。今回はゲームとして成立するかを確認する段階なので、盤面、手番、勝利判定、終了状態をフロント内で完結させた。

勝利判定は UI コンポーネントへ直書きせず、`_lib/game.ts` に分けた。後でオンライン対戦へ進む場合も、同じ判定ロジックを使いやすくするため。

## 検討した代替案

- オンライン対戦を同時に作る
  - 初期実装として重すぎるため見送った。
- 5連続勝利にする
  - ユーザー要件が4マス連続だったため採用しない。
- 勝利ライン以外も隠す
  - ゲーム性が分かりにくくなるため、完成した4マスだけを隠す。

## トレードオフ

- 現時点では同じ端末でのローカル対戦のみ。
- 勝敗履歴やスコア保存はない。
- その代わり、実装範囲が小さく、ルールの修正がしやすい。

## 今後の見直し条件

- オンラインランダム対戦を作る。
- 勝敗履歴、連勝数、共有導線を追加する。
- ルール説明や演出を増やす。
