# #154 爆音危機一髪のUI/UXを整える

## 背景

#94 でMVPとして爆音危機一髪を追加した。#154 では公開に向けて、最初の画面の文字量を落とし、人数選択から音量確認へ進む流れを明確にする。

## 決定したこと

- テーマを `tomato` から `sumi` へ変更した。
- 開始前の状態を「人数選択」と「音量確認」の2フェーズに分けた。
- 最初の説明文、Statusラベル、人数ラベル、音量確認の説明文をApp画面から削除した。
- 人数選択は複数ボタンを並べず、現在人数を中央に置き、左右の `−` / `＋` で増減するUIへ変更した。
- 人数は2人から10人まで選べるようにした。
- 人数選択フェーズの表示は「プレイヤー人数選択」、音量確認フェーズの表示は「音量を上げる」とした。
- 開始前のフェーズ表示は外側のステータス帯ではなく、操作ボタンのあるカード内に収めた。
- 音量確認フェーズは円形の囲みを置かず、`READY` だけを小さめに表示した。
- 人影は、2=2、3=3、4=4、5=3+2、6=3+3、7=4+3、8=4+4、9=5+4、10=5+5 の行分割にした。
- 人影は顔と体を分けず、1つの丸みのあるシルエットにした。
- ゲーム開始後の表示も短くし、セーフ数と爆音結果だけを表示する。
- ゲーム中のステータスは押したSAFE数ではなく、残りSAFE数を表示する。
- ボタン押下後すぐに判定せず、下からアクセント色が満ちる判定待ち演出を挟む。
- セーフ時の音は鳴らさず、アウト時だけ音を鳴らす。
- アウト時の音量と画面のアクセント色演出を強める。

## 理由

このアプリは、説明を読ませるよりも同じ画面を囲んで緊張感を作ることが主目的である。最初の画面に文章が多いと、遊びの前にテンポが落ちる。人数選択と音量確認を分けることで、音量を上げる行為を儀式として見せつつ、画面上の文章は最小限にできる。

## 検討した代替案

- 音量確認を説明文で残す案: Issueで削除対象に含まれていたため採用しなかった。
- 人数選択に四角いボタンを複数並べる案: 選択肢感が強く出すぎるため、中央表示と増減ボタンに変更した。
- 人数選択に「人」や長い説明ラベルを付ける案: 視覚だけで伝える方針に合わせ、数字と人影を主役にした。
- 音量確認で `MAX` と表示する案: コメントで「ダサい」と指摘があったため、`READY` に変更した。
- `READY` を円で囲む案: 追加確認で不要と分かったため、文字だけにした。
- セーフ時にも短い音を鳴らす案: 授業中などの遊び方ではセーフの人まで被害を受けるため、無音にした。
- 押した瞬間に即判定する案: ハラハラ感が出ないため、判定待ち演出を挟む形にした。
- ゲームロジックを変更する案: #154 の範囲外のため触らなかった。

## トレードオフ

- 文字を削った分、初見の説明力はGuideページへ寄る。
- 人影はCSSだけで作っているため、細かいイラスト表現はない。

## テスト・検証内容

- App画面に削除対象の文言が戻らないことをunit testで確認する。
- `sumi` テーマを使うことをunit testで確認する。
- 人数ごとの人影の行分割をunit testで確認する。
- 残りSAFE表示、セーフ音なし、判定待ち演出をunit testで確認する。

## 今後の見直し条件

- 実機確認で人数ボタンの人影が読み取りづらい場合は、別Issueでアイコン表現や余白を調整する。
- 音量確認フェーズの演出を強める場合も、別Issueで扱う。
