# #161 爆音危機一髪のAboutとGuideを整える

## 背景

爆音危機一髪はMVPとUI改善が進み、動画制作へ進む前にアプリ側の説明を整える段階になった。現状のAboutとGuideは最低限の情報を持っていたが、動画から来た人や初めて遊ぶ人が、何を面白がるアプリなのか、どう始めればよいのかを理解するには薄かった。

## 決定したこと

- Aboutは、本人が書いた「鳴らしたくないけど誰かに鳴らしてほしい」という動機と、途中で切れる注意文の味をそのまま残した。
- Guideは、2人から10人の人数選択、音量確認、順番の決め方、負け条件、音が出ない場合の確認先を明確にした。
- Guideに操作画面の模式図を追加する案は、このアプリには少し大げさなため採用しない。
- 公開までの後続Issueとして、動画制作の #162 と公開準備の #163 を作成した。
- App本体のUI、ゲームルール、YouTube URL、公開設定、OG画像は触らない。

## 理由

動画制作前にアプリ側の説明を固めておくと、動画の構成を考えるときに「何を説明すべきか」がぶれにくい。Aboutは本人の衝動が一番強く出る場所、Guideは初回プレイの摩擦を減らす場所として役割を分けた。

Aboutの最後にある崩れた注意文は、爆音危機一髪の空気に合う本人の言い回しとして残す。整えすぎると、このアプリの「やるなと言われるほどやりたくなる」感じが薄くなる。

## 検討した代替案

- App画面に説明を追加する案: App画面はすぐ遊べる場所として保つ方針のため採用しない。
- YouTube導線を先に置く案: 動画URLと公開準備は別Issueで扱うため採用しない。
- Guideへ操作画面の模式図を載せる案: スクリーンショットよりは古くなりにくいが、このアプリの単純さに対して少しお粗末に見えるため採用しない。
- Aboutを整った制作裏話にする案: 本人の言葉の勢いが弱くなるため採用しない。

## トレードオフ

- Aboutの文章は本人の味を残すため、通常の説明文より崩れた表現を含む。
- Guideの説明量は増えたが、初見で複数人プレイを始めるための情報を優先した。

## テスト・検証内容

- `npm run format`
- `npm test -- test/unit/apps/bakuon-kikiippatsu/app-page.test.ts`
- desktopとmobileでAbout / Guideを表示し、横overflowとconsole errorがないことを確認した。

## 今後の見直し条件

- 実際に初見の人が遊んで迷う箇所が出たらGuideを更新する。
