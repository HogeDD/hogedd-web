# ニシ打の公開前文言を確認する

## 背景

ニシ打は、実在人物、動画、コメントを扱うアプリである。公開前に、出題文、About、Guide、参考リンクの扱いを人間が確認し、必要な文言修正を小さく反映する必要があった。

## 決定したこと

- Issue #147のコメントで確認された参考リンク名として、Aboutの参考リンクに「タイピングできないニシダ」を表示する。
- 参考リンクの説明は、企画のきっかけになった元コメントに触れる既存文のまま残す。
- Guideの「ランクDでも大丈夫。漫才と同じで、タイピングも場数。」を削除する。
- 出題文、読み、タイピングエンジン、スコア計算は変更しない。
- YouTube公開URL、OG画像、`published`化は公開準備Issueへ残す。

## 理由

AboutとGuideの本文は公開時の見え方に直結するため、AIが追加で言い換えたり盛ったりせず、Issueコメントで人間が指定した範囲だけを反映する。特にGuideの削除指定はトーンの調整であり、ゲーム仕様には影響しない。

## 検討した代替案

### Guideのtipsへ別の文言を追加する

5セクションの必須条件を満たすために別文言を追加する案もあるが、既存のIME確認文だけで`tips`は空にならない。AIが新しい一言を足す必要はないため採用しない。

### 参考リンク名を汎用的な説明のまま残す

リンク先の役割は伝わるが、Issueコメントでは動画名として「タイピングできないニシダ」が示されている。公開前確認のIssueでは、人間が指定した表示名へ寄せる方を優先する。

## トレードオフ

- 参考リンク名だけでは、動画内のどのコメントがきっかけかは分からないため、説明文で補う必要がある。
- Guideの軽い一言を削るため、案内文は少し実務寄りになる。

## テスト・検証内容

- Aboutに確認済みの参考リンクURL、ラベル、説明が残ることをunit testで確認する。
- Guideから削除指定の文言が消え、tipsが残ることをunit testで確認する。

## 今後の見直し条件

- 参考リンクの動画URLや表示名を変更するとき。
- 公開準備IssueでYouTube公開URL、OG画像、`published`化を扱うとき。
