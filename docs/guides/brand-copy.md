# HogeDD Brand Copy Guide

HogeDD のホーム画面やアプリ紹介で使う言葉の方針をまとめる。文章は増やしすぎず、短い言葉を強く見せる。

## Core Message

### Main

```text
Hoge Driven Development
```

HogeDD の中心になる言葉。ホームの hero では、この言葉を主役として扱う。

### Sub

```text
人は欲望によって進歩する
```

HogeDD が扱う「作りたい理由」を肯定する言葉。軽い動機や個人的な欲望を、開発の出発点として扱う。

### Third

```text
その衝動には価値がある
```

思いつきや衝動を、恥ずかしいものではなく価値のあるものとして見せる言葉。

### Longer Copy

```text
モテたい。
楽をしたい。
やってみたい。
理由はそれで十分だ。
```

HogeDD の空気を説明するための少し長いコピー。必要な場面でだけ使う。常に全文を出す必要はない。

## 言葉の方針

- 人間の欲望や衝動を否定しない。
- 軽い動機を、開発のきっかけとして肯定する。
- くだらなさや遊び心は扱ってよい。
- ただし、言葉は前向きに見せる。
- 文章量を増やしすぎず、短い言葉で伝える。
- ホームでは説明文よりも、コピー、余白、ビジュアルで伝える。

## 使わない言葉

ブランディングでは、ネガティブな言葉を避ける。

使わない例:

```text
クソアプリ
クソゲー
くだらないだけ
しょうもないだけ
```

理由:

- HogeDD は衝動や欲望を肯定するブランドであり、自分たちの作ったものを雑に下げるブランドではない。
- 軽い動機や遊び心は見せたいが、価値がないものとして見せたくない。

## UI で使うときの注意

- hero では `Hoge Driven Development` を主役にする。
- `人は欲望によって進歩する` と `その衝動には価値がある` は、サブコピーとして扱う。
- 長い説明が必要な場合だけ `モテたい。楽をしたい。やってみたい。理由はそれで十分だ。` を使う。
- アプリカードやボタンでは、短く分かりやすい言葉を使う。
- ネガティブ語で目立たせるのではなく、前向きな違和感で印象を作る。

## 見直し条件

- ホーム hero の実装時に、コピーの表示順や量が合わないと分かったとき。
- HogeDD の思想やブランドトーンをさらに整理するとき。
- アプリが増え、紹介文の言葉にばらつきが出たとき。
